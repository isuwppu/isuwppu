# Tetris

A browser-based Tetris game built with vanilla HTML, CSS, and JavaScript.

## Features
- All seven tetrominoes
- Rotation and wall kicks
- Soft/hard drop and ghost piece
- Line clearing, score, levels, increasing speed
- Pause/restart
- Responsive touch controls
- No dependencies or build step

## Run
Open `index.html` in a modern browser.

## GitHub Pages
In **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.

## Controls
- ← / → Move
- ↓ Soft drop
- ↑ Rotate
- Space Hard drop
- P Pause
- R Restart
